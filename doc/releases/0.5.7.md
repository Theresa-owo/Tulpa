# Tulpa 0.5.7 · B站浏览、统一 MCP 授权与命令行

本版只发布 Windows MCP 版和 Linux MCP 终端源码包，旧完整版停止维护。

## 新增与改进

- **B站浏览**：同一 MCP 连接内授权搜索、推荐、视频详情与分 P、字幕、真实抽帧和评论。媒体处理异步执行，可查询或取消；无字幕时可使用已安装的本地 ASR 模型。B站侧只读，不提供社交写操作，不增加模型 API。
- **统一连接界面**：首页保留创建入口和紧凑的可折叠连接列表，支持单独启停与删除。QQ、微信、哔哩哔哩各有模块总开关；未启用模块不进入授权，连接名称可自动生成。
- **导入按需**：只使用实时 QQ、持续水群或 B站无需导入聊天资料；选择历史读取且缺资料时才提示导入。学习内容从左侧按 QQ 账号与群号管理。
- **Windows 命令行**：新增 `Tulpa.CLI.exe`，Agent 可不操作图形界面，直接配置连接、管理 QQ/B站状态、查询学习库并调用已授权工具。复用原服务与权限，不开启第二套模型。
- **SnowLuma 自动配置**：使用固定验证的 2.1.1 适配；Windows 包可直接校验随包的官方原始归档，完成初始化、端口和凭据托管。已获得作者书面同意，遵守不修改 SnowLuma 本体的条件。[授权记录](../assets/SnowLuma.png)
- **稳定性**：修复长材料处理的 WebSocket 保活及测试预算；补齐 Linux 启动器测试副本的 B站模块，修正跨平台文档与授权界面测试时序。Windows、Linux x86_64 和 ARM64 的 CI 均纳入新 MCP / B站 / CLI 检查。

- **仓库整理**：Linux 指南与测试须知集中到 `doc/`，Windows 辅助脚本移至 `scripts/windows/`；主要运行入口保持原位，发行包仍提供根目录 README 与测试说明。

## 下载与启动

- `Tulpa-MCP-0.5.7-win-x64.zip`：完整解压后打开 `Tulpa/Tulpa.exe`；命令行打开 `Tulpa/Tulpa.CLI.exe`。需要系统 WebView2 Evergreen Runtime 和 .NET Framework 4.8。
- `Tulpa-MCP-0.5.7-linux.tar.gz`：x86_64 / ARM64 终端源码包，进入解压目录执行 `./tulpa`。需要 Python 3.13 或 uv，首次安装联网获取依赖；不附带 Windows 运行时、QQ 或账号登录数据。
- `SHA256SUMS.txt`：发行文件校验值；`FFmpeg-b08d7969c5-source.tar.gz`：Windows 媒体运行库对应源码。

## 升级

Windows 按 [保留数据升级](../UPGRADE.md)，Linux 按 [Linux 升级说明](../LINUX_UPGRADE.md)。先停止后台并备份，保留连接授权、数据、学习库及自改人格，升级后重连 MCP 并刷新工具。旧连接不会自动获得 B站等新增权限。两份小鲸鱼与龙娘原卡保持现有内容。

## 验证与限制

随包运行时、隔离 MCP、授权与媒体夹具、Linux 启动与发行清单用于验证工程链路；远端执行 Windows、Linux x86_64 / ARM64 检查，发布结果附在 GitHub Release。包内清单记录来源提交和文件哈希。

B站搜索、推荐、字幕、真实画面和评论已在 Windows 使用测试账号验证；Linux 为离线回归，未重复真实扫码和媒体读取。无字幕 ASR 的完整视频实测尚未完成；少量画面不等于完整视频理解。

QQ 原生 B站卡片实测提示小程序已下架，跳转未通过，创建界面已移除分享授权入口，无法核验的卡片会被拒绝。本版不将其列为可用分享功能。

本次打包不发送真实 QQ 消息、不操作 B站账号、不改动用户安装数据，也不以测试夹具证明真实学习质量或所有客户端兼容。
