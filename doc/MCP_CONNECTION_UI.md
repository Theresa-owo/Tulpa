# MCP 连接界面

首页点击「开始创建链接」，选择 QQ、微信、哔哩哔哩模块并勾选功能，然后点击「一键开启 MCP」。名称可留空，自动生成 `mcp-` 开头的 ID。

- 取消模块总开关后，该模块的权限、历史平台与会话选择均不进入新连接；服务端也会过滤隐藏字段。现有连接不自动获得新权限。
- QQ 的 SnowLuma 配置在 QQ 模块内。仅开启发送或持续水群时不要求导入历史记录；勾选历史读取且本机缺少资料时才显示导入提示。
- 历史附件选项、日期和名称在折叠的高级设置内。会话范围仍须主动选择。视频卡片分享入口已从创建界面移除。
- 首页连接列表可折叠。开关关闭连接并取消其等待、学习与发送队列；重新开启后使用原凭据重新连接宿主，需要聊天时重新开始会话。已经交给 QQ 的操作无法撤回。
- 垃圾桶永久删除凭据及连接配置；不会删除聊天数据、按账号和群保存的学习库。删除后重新创建会得到不同凭据。
- 左侧「B站账号设置」打开扫码窗口；「QQ 学习管理」按机器人 QQ、群号浏览和修改本地学习记录，离线或删除 MCP 连接后仍可管理。此管理入口仅供本机界面，MCP 工具仍按当前授权核验。
- 可选语音组件和模型下载入口已隐藏，服务端转写、组件安装接口及已安装资源保留。

新增 `grants.paused` 是兼容的 SQLite 增量字段，原连接默认保持原状态。暂停及恢复会增加权限版本，旧的在途结果不可重新使用。

验证：`python scripts/check_mcp_connection_ui.py`；安装 Playwright 后执行 `node scripts/check_mcp_ui.cjs`。后者用实际页面和合成 HTTP 数据检查交互及窄屏，不会发送真实 QQ 消息或创建真实 B站登录。
